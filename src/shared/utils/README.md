# utis/

This folder contains shared utilities and helpers used by various components across the Atlaset application. Below is an overview of each subfolder and its purpose:

## Folder overview

- [`browser/`](./browser/)  
  Handles web browser actions and API interaction, including URL detection and device operations.

- [`collection/`](./collection/)  
  Tools for organizing groups of data, such as comparison, filtering and sorting.

- [`date/`](./date/)  
  Helpers for date and time formatting and calculations.

- [`files/`](./files/)  
  File management utilities for handling files, including imports, exports and MIME validation.

- [`primitives/`](./primitives/)  
  Low-level formatting and type operations for numbers, strings, booleans and objects.

- [`ui/`](./ui/)  
  Presentational helper methods for visual elements and styling.
