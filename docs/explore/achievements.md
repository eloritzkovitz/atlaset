# Achievements

The **Achievements** section tracks your personal travel milestones and goals, based primarily on your trip and visit data as well as your interaction with the application. For convenience, achievements are grouped into types, making them easier to follow.

You can search and filter achievements by name, type or status at the top of the achievements section.

## Earning achievements

Achievements are earned automatically by achieving the required criteria. This can be visiting a certain count of countries, specific countries in a region, subregion or feature, visiting a country more than once and so on.

## Achievement types

| Type            | Description                                                                        |
| --------------- | ---------------------------------------------------------------------------------- |
| **Milestone**   | Achievements for completing milestones - completing regions or subregions.         |
| **General**     | Achievements based on general activity or progress.                                |
| **Collection**  | Achievements for completing specific sets of achievements.                         |
| **Geographic**  | Achievements based on visiting countries in specific regions or geographic areas.  |
| **Historic**    | Achievements related to historical empires or past events.                         |
| **Cultural**    | Achievements related to cultural characteristics associated with countries.        |
| **Affiliation** | Achievements based on country affiliations and relationships.                      |
| **Trips**       | Achievements based on trip activity, such as trip count, duration or destinations. |

## Tracking progress

Each achievement shows its completion status and progress towards completion. Some achievements can be tiered, and the full tier list can be seen by hovering over the progress indicator.

Achievements can have one of the following statuses:

| Status          | Description                                                             |
| --------------- | ----------------------------------------------------------------------- |
| **Locked**      | The achievement has not yet been completed and has no current progress. |
| **In Progress** | You have made progress towards completing the achievement.              |
| **Completed**   | All requirements for the achievement have been met.                     |
