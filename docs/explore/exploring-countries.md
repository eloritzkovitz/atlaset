# Exploring countries

The **Countries** section in **Explore** provides a dedicated way to browse and discover countries and territories.

## Differences from the Atlas

Both the Atlas Countries panel and the Explore Countries section provide access to the same information, but are designed for different ways of browsing experience:

- **In the Atlas**, countries are integrated with the interactive map. You can organize them into lists, layers and markers, and take advantage of additional map-related functionality, including qualifier search and context-specific filters.
- **The Explore section** focuses on dedicated browsing and discovering of countries, with an additional grid layout view and sequential navigation. Additionally, countries you have visited will be fully colored, while unvisited ones will be grayed out.

For information about country details and functionality, see more about [countries in the Atlas](/docs/atlas/countries.md).

## Browsing countries

You can search, filter and sort countries using the available controls.

- Use the search bar to find countries by name.
- Filter countries by **region** and **subregion**.
- Show **sovereign countries only**.
- Show **visited countries only**.
- Include **transcontinental countries**.
- Sort countries using the available sorting options.

> <icon name="info"></icon> **Note**
>
> Differently from the **Countries** panel in the Atlas, the Explore view uses regular text search and does not support [qualifier search](/docs/search/country-search.md).

## Viewing countries

The Explore countries display supports two views:

|                                                  |                                                    |
| ------------------------------------------------ | -------------------------------------------------- |
| <icon name="viewMode.grid"></icon> **Grid View** | Displays countries as an interactive grid of flags |
| <icon name="viewMode.list"></icon> **List view** | Displays countries in a more compact list          |

Use the **view toggle** to freely switch between the two modes.

## Navigating countries

When viewing a country, use the **Previous** and **Next** controls to move through the countries in the current browsing context.

Navigation respects the relevant search and filter criteria, allowing you to browse through a filtered set of countries without returning to the country list.

The **Back** button next to the country's header will navigate back to the country list.
