# Explore overview

The **Explore** section provides tools for discovering information about the world and tracking your personal exploration progress.

You can browse and search geographic and reference data, or track your progress through countries, achievements, and other exploration activities.

## Sections

| Section          | Description                                                                                 |
| ---------------- | ------------------------------------------------------------------------------------------- |
| **Progress**     | Track your world exploration and travel progress.                                           |
| **Discover**     | Learn more about countries and various aspects of the world.                                |
| **Countries**    | View detailed information about countries.                                                  |
| **Languages**    | View detailed information about languages and where they are spoken.                        |
| **Currencies**   | View detailed information about currencies and the countries and territories that use them. |
| **Timezones**    | View detailed information about timezones and their associated countries.                   |
| **Achievements** | Track personal travel milestones and goals.                                                 |

Data can be searched and filtered where applicable, and supported lists can be displayed in either **grid** or **list** mode.
