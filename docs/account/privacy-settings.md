# Privacy settings

Privacy settings let you control your data.

## Profile visibility

You can control whether your profile is **public** or **private**.

- A **public profile** can be viewed by other users.
- A **private profile** restricts profile information from users who do not have access to it.

By default, your profile will be set to **public**. If you wish to set it private, follow these steps:

1. In the sidebar, click <icon name="settings"></icon> **Settings**.
2. In the **Settings** menu, look for <icon name="privacy"></icon> **Privacy**.
3. Under **Visibility**, find **Show my profile to others** and toggle it off.

### Search indexing

You can control whether your profile is allowed to appear in user search and other search indexing.

Search indexing can only be configured when your profile is **private**. Public profiles are automatically available for search.

Disabling search indexing prevents your profile from being included in user search results.

To disable search indexing, toggle the **Allow search indexing** option off.

## Analytics

Atlaset uses **Firebase Analytics** for analytical purposes and to help improve the application and user experience. Analytics collection is optional and can be declined without affecting any functionality.

> <icon name="info"></icon> **Note**
>
> Analytics data is collected anonymously and does not include personal or private information.

The first time you use Atlaset, a consent window will ask whether you want to allow analytics collection. You can choose to accept or decline.

You can change this setting at any time:

1. In the sidebar, click <icon name="settings"></icon> **Settings**.
2. In the **Settings** menu, look for <icon name="privacy"></icon> **Privacy**.
3. Under **Analytics**, find **Share anonymous usage data** and toggle it on/off.

For more information on how we collect and use data, see the [Privacy policy](/privacy).
