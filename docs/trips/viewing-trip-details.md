# Viewing trip details

Open a trip from the **Trips** list to view a detailed page, bringing together the main information and content for the trip.

| **Section**      | **Description**                                                                                                                                                                                             |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Overview**     | Shows the trip's `name`, `dates`, `status`, `rating`, `favorite` and `shared` state when available. You can also navigate between trips in chronological order, return to the trip table, edit, customize or copy the trip. |
| **Destinations** | Shows the selected locations grouped by country and region alongside an interactive map.                                                                                                                    |
| **Gallery**      | Shows uploaded trip photos and provides access to an external photo album when one is linked.                                                                                                               |
| **Details**      | Shows participants, categories and tags associated with the trip.                                                                                                                                           |
| **Notes**        | Shows the trip's additional notes.                                                                                                                                                                          |
