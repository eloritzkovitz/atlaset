# Leaderboards

Leaderboards show the best quiz scores, showing the 25 best `scores` of each `quiz type` and `difficulty` combination!

Each entry will show the `rank`, `player name`, `score`, `max streak`, `completion time` and `date`.

### **Ranking priority**

Ranking priority follows `score` > `max streak` > `time`.

## **Personal scores**

For each player with leaderboard entries, they will also show in the player's profile.
