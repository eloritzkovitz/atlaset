# Using Atlaset

## What is Atlaset?

Atlaset is an application designed to provide users with an interactive way to track and organize their travels. Users can interact with a world map, add and manage lists, layers, markers and trips, follow their progress and share their journeys and milestones with friends.

## Navigation

Use the main sidebar to switch between the different sections of the application. Each section provides tools and controls specific to its purpose.

### The sidebar

|                                              |                                                                                                                                  |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| <icon name="atlas"></icon> **Atlas**         | Explore an interactive world map, browse countries, track visits, create lists, add layers and markers, and save or export maps. |
| <icon name="explore"></icon> **Explore**     | Browse countries and world reference data, and track your exploration progress through regions, countries and achievements.      |
| <icon name="trips"></icon> **Trips**         | Create and manage trips, organize destinations and itineraries, add photos, view trip details, and share trips with others.      |
| <icon name="quizzes"></icon> **Quizzes**     | Test your geographic knowledge through quizzes and compare your scores on leaderboards.                                          |
| <icon name="atlas"></icon> **Search**        | Search Atlaset data using regular search and advanced country search syntax.                                                     |
| <icon name="dashboard"></icon> **Dashboard** | View an overview of your activity, travel data and statistics.                                                                   |
| <icon name="settings"></icon> **Settings**   | Configure your account, preferences and application settings.                                                                    |

### The app header

Additional, application-wide controls can be accessed from the app header, such as help, notifications and the user menu.

## Core concepts

|                        |                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------- |
| **Atlas**              | The interactive world map where you can explore countries and create your own maps, layers and markers. |
| **Countries**          | Represent the places you can explore and track.                                                         |
| **Visits**             | Represent the countries you have visited.                                                               |
| **Country lists**      | Let you organize countries into predefined or custom groups.                                            |
| **Layers and markers** | Let you group and mark countries on the map.                                                            |
| **Saved maps**         | User-made custom maps containing layers and markers.                                                    |
| **Timeline**           | An interactive chronological display of your visits on the map.                                         |
| **Trips**              | Contain detailed information about your travels.                                                        |
| **Achievements**       | Track milestones and progress related to your exploration.                                              |
