# Search overview

Atlaset provides search tools for quickly finding users, countries and other geographic data across the application. Search results are ranked by relevance and grouped by result type.

## Search types

### Global search

Use the **Global Search** in the main application header to search across multiple types ofdata from a single search field.

Global search supports finding the following data:

| Type           | Search by                      |
| -------------- | ------------------------------ |
| **Users**      | Display name                   |
| **Countries**  | Country name                   |
| **Currencies** | Currency name or ISO 4217 code |
| **Languages**  | Language name or ISO 639 code  |
| **Timezones**  | Timezone code                  |
| **Regions**    | Region name                    |
| **Subregions** | Subregion name                 |

Results are ranked by relevance, with more closely matching results appearing first.

### Feature search

Some features have their own respective search, narrowed down to query only the relevant data. In that case, they will have their own search input.

### Qualifiers and modifiers

Some features allow for more advanced search, using a more complex syntax to filter items using more detailed search criteria.
