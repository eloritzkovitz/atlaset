# Legend

The map legend helps you interpret the country colors displayed on the Atlas map. It provides a key to understand what each visual color represents, making it easier to explore and analyze map data.

The legend appears as a panel on the top right of the map interface. It lists all the `layers` and special features currently visible on the map, along with their corresponding colors.

`Legend` can be toggled on/off from the `map toolbar` or by pressing the <kbd>G</kbd> key.
